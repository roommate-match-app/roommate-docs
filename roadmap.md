# План разработки проекта (Roadmap)

Проект: **«КакДостать Соседа»**  
Технологический стек:
* **Backend:** Python (FastAPI, SQLAlchemy, Alembic, Pydantic)
* **Frontend:** React (TypeScript, Vite, TailwindCSS / UI Kit)
* **Database:** PostgreSQL 16
* **DevOps / Окружение:** Docker, Docker Compose

---

### Фаза 2. Реализация ядра системы (Подготовка к Лабораторной работе №3)
**Цель:** Реализовать сквозные пользовательские сценарии от базы до интерфейса.

#### Итерация 2.1: Профили и анкеты (UC-1 – UC-4)
* **БД:** Реализация таблиц `users`, `profiles`, `questionnaires`, `preferences`.
* **Бэкенд:** JWT-авторизация (регистрация/логин), CRUD для анкеты сожителя и предпочтений.
* **Фронтенд:** Экран авторизации, пошаговый мастер заполнения и редактирования анкеты.

#### Итерация 2.2: Подбор и механизм мэтчинга (UC-5, UC-6)
* **БД:** Таблицы `likes`, `matches`, индексы для поиска по фильтрам (метро, бюджет, привычки).
* **Бэкенд:** Алгоритм расчета процента совпадения анкет, фильтрация списка, обработка взаимного лайка и генерация сущности `match`.
* **Фронтенд:** Каталог карточек кандидатов с фильтрами, кнопка «Мне подходит!», экран взаимных совпадений.

#### Итерация 2.3: Чаты и коммуникация (UC-7, UC-8)
* **БД:** Таблицы `chats`, `messages`, `notifications`.
* **Бэкенд:** REST/WebSocket эндпоинты отправки и получения сообщений, фиксация прочтения, генерация уведомлений.
* **Фронтенд:** Интерфейс переписки, список диалогов, отображение уведомлений в шапке.

#### Итерация 2.4: Объявления жилья и отзывы (UC-9, UC-10)
* **БД:** Таблицы `housing`, `rooms`, `applications`, `reviews`.
* **Бэкенд:** Публикация объявлений от арендаторов с жильем, подача заявок на подселение, добавление отзывов с расчетом рейтинга.
* **Фронтенд:** Карточка объявления жилья, форма отзыва в профиле сожителя.

### Фаза 3. Стабилизация и защита (Финал)
**Цель:** Соответствие всем критериям приемки и проведение презентации.

1. **Интеграционное тестирование:** Проверка позитивных сквозных сценариев (регистрация -> мэтч -> чат -> отзыв).
2. **Очистка и документация:** Актуализация Swagger, проверка чистоты Git-истории (отсутствие мусорных коммитов в `main`).
3. **Демонстрация:** Проверка старта всего стека на чистой машине через Docker (до 8 ГБ RAM), подготовка слайдов презентации.
