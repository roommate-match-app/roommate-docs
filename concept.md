# Концепция и функциональные требования
## 1. Идея и проблема
Большинство сервисов недвижимости решают задачу «найти жильё», но не решают задачу «найти человека, с которым это жильё делить». 
«КакДостать Соседа» переворачивает порядок действий обычного поиска жилья: сначала найти подходящего соседа -> затем вместе найти жильё.

Сервис объединяет пользователей с похожими требованиями к совместному проживанию через анкеты, фильтруемый подбор и систему взаимного интереса, а после даёт им общий чат.

## 2. Роли пользователей
* **Гость:** Неавторизованный посетитель, видит только экран входа/регистрации.
* **Пользователь:** Авторизован, заполнил анкету, использует основной сценарий «найти соседа -> найти квартиру».
* **Арендатор с жильём:** Пользователь, у которого уже есть квартира и который ищет соседа для подселения (обратный сценарий).

## 3. Пошаговый сценарий
1. **Анкета:** После регистрации пользователь создает анкету (имя, фото, бюджет, привычки). Отдельно хранятся предпочтения к будущему соседу.
2. **Подбор:** Пользователь задаёт фильтры и получает список чужих анкет, ранжированный по степени совпадения.
3. **Взаимный интерес:** Пользователь ставит отметку «Мне подходит!». При обоюдном интересе фиксируется совпадение и создаётся чат.
4. **Чат:** Единственный канал прямого общения для обсуждения условий.
5. **Совместный поиск квартиры:** Обмен ссылками на внешние объявления (ЦИАН и т.д.) внутри чата.
6. **Обратный сценарий («Ищу соседа»):** Арендатор размещает объявление, другие пользователи отправляют заявки на подселение.

## 4. Ключевые функциональные возможности
* **FR-1 — FR-3:** Регистрация, вход, просмотр и редактирование базовых данных профиля.
* **FR-4 — FR-7:** Создание и редактирование анкеты, указание предпочтений, загрузка фото.
* **FR-8 — FR-10:** Фильтрация и просмотр анкет.
* **FR-11 — FR-13:** Отметка «Мне подходит», фиксация взаимного совпадения.
* **FR-14 — FR-16:** Автоматическое создание чата, отправка сообщений, история переписки.
* **FR-20 — FR-25:** Публикация объявлений на подселение, фильтрация, отправка и обработка заявок.
* **FR-28 — FR-29:** Оставление отзывов о пользователях.

## 5. Ограничения первой версии
* Нет автоматического парсинга объявлений с внешних площадок — только ручной обмен ссылками внутри чата.
* Нет интеграции с внешними сервисами недвижимости на первом этапе.
* Модерация жалоб выполняется вручную.
