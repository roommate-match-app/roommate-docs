# Варианты использования (Use Cases)

В документе зафиксирован согласованный перечень Use Cases (MVP-версия) сервиса «КакДостать Соседа».

## Акторы
* **Пользователь** — авторизованный пользователь системы, ищущий соседа для совместной аренды.
* **Арендатор с жильём** — пользователь, у которого уже есть квартира/комната и который ищет соседа для подселения (специализация роли Пользователь).

---

## Таблица Use Cases

| ID | Актор | Прецедент (Use Case) | Описание сценария | Предусловие | Ожидаемый результат |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **UC-1** | Пользователь | Регистрация | Создание новой учётной записи с указанием базовых данных (email, пароль, имя) | Пользователь не авторизован в системе | Учётная запись создана, выполнен автоматический вход |
| **UC-2** | Пользователь | Создание анкеты | Первичное заполнение профиля сожителя (бюджет, метро, привычки, фото, режим дня) | Аккаунт создан, анкета отсутствует | Анкета сохранена и становится доступна в ленте подбора |
| **UC-3** | Пользователь | Выбор предпочтений о соседе | Указание критериев желаемого сожителя (диапазон возраста, бюджет, отношение к животным/курению) | Анкета создана | Предпочтения сохранены и используются для фильтрации и расчета совпадения |
| **UC-4** | Пользователь | Редактирование анкеты | Изменение контактных данных, бюджета, бытовых требований или описания о себе | Анкета создана | Обновленные данные сохранены и отражаются в подборе |
| **UC-5** | Пользователь | Просмотр анкет | Просмотр ленты анкет потенциальных сожителей с применением фильтров по критериям | Анкета создана | Отображен список карточек кандидатов с процентом совместимости |
| **UC-6** | Пользователь | Отметить «Мне подходит» | Проявление интереса к кандидату (лайк анкете). При взаимной отметке фиксируется совпадение | Открыта детальная карточка чужой анкеты | Отметка сохранена; при взаимности генерируется общий диалог |
| **UC-7** | Пользователь | Переписка в чате | Обсуждение условий проживания, бытовых правил и обмен ссылками на варианты квартир | Чат создан (при взаимном интересе или принятии заявки) | Сообщения отправляются и отображаются в истории переписки |
| **UC-8** | Пользователь | Получение уведомлений | Отображение системных оповещений (новый лайк, взаимный match, новое сообщение в чате) | Наступление триггерного события в системе | Уведомление доставлено пользователю и отображено в интерфейсе |
| **UC-9** | Пользователь | Оставить отзыв | Выставление оценки (1–5) и текстового комментария о человеке по результатам общения или совместного проживания | Состоялся контакт / диалог между пользователями | Отзыв сохранен и отображается в публичном профиле кандидата |
| **UC-10** | Арендатор с жильём | Разместить объявление квартиры на сожительство | Публикация объявления с характеристиками имеющегося жилья (адрес, стоимость комнаты, фото, требования к жильцу) | Пользователь авторизован в системе | Объявление опубликовано и доступно другим пользователям для отклика |

---

## Заметки по реализации
1. **Связка UC-5 и UC-6:** Чат создается только при подтверждении обоюдного интереса (взаимный лайк), что защищает пользователей от спама.
2. **Вторичный сценарий (UC-10):** Позволяет закрыть обратный путь поиска, когда квартира уже найдена одним из арендаторов.
